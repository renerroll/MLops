Notes:
- Both containers were run with the repository mounted at /app so they use the current `inference.py`, `model.pt`, and `imagenet_classes.txt` from the repo.
- Images processed: files found under `images/` (common image extensions only).
- Model exported with torchvision MobileNet v2 weights and traced to TorchScript (`export_model.py` using `models.mobilenet_v2(weights=models.MobileNet_V2_Weights.DEFAULT)` then `torch.jit.trace`).
- I re-exported `model.pt` inside the project's `.venv` before running containers to avoid archive errors.
- You will commit this file yourself per your request.

Command used (example):
- docker run --rm -v "$PWD":/app mobilenet-fat:latest python /app/inference.py /app/images/<image>
- docker run --rm -v "$PWD":/app mobilenet-slim:latest python /app/inference.py /app/images/<image>
